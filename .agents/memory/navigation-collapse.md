---
name: Navigation collapse
description: Client navigation must stay out of the way until deliberately opened.
---
The side navigation must start collapsed until the user intentionally opens it. Keep the top bar compact with icon-only menu and profile controls. Do not collapse dashboard financial content or debt warnings.

**Why:** The user asked that the dashboard navigation always be collapsed and that the large top bar remain collapsed until intentionally opened.

**How to apply:** Keep clear, touch-friendly open/close controls and keyboard access. Start collapsed on entry, reload and route changes, regardless of old expanded-state cookies. Do not open on hover or scrolling. Settings and all existing navigation remain reachable from the drawer. The top-right profile icon opens the personal profile page; keep client identity, avatar and sign-out there, not in the drawer.

**Why:** The user replaced the expandable Navigation control with a profile icon and explicitly moved the sidebar's identity and logout controls to that page.

Use the approved cream slide-out menu with full labels and grouped account/personal links rather than a persistent icon rail.

**Why:** The user chose the slide-out menu after comparing the navigation designs.

**How to apply:** Keep this visual direction and deliberate opening behavior for future navigation changes unless the user requests a different design.
